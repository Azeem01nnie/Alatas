# Alatas Car Rental Services

```
Alatas/
├── frontend/   # React customer panel + admin
├── backend/    # Express API
├── start.bat   # One-click start (Windows)
└── package.json
```

## One-click start (recommended)

Double-click **`start.bat`** in the `Alatas` folder.

That starts frontend + backend together and opens **http://localhost:5173**.

Or from a terminal in `Alatas`:

```bash
npm install
npm start
```

## Separate commands (optional)

```bash
npm run dev:app    # frontend only
npm run dev:api    # backend only
```
