# Customer Encoder

Minimalist React stepper app for encoding lessee/renter registration records.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Steps

1. **Personal Info** — Name, address, contact, emergency contact
2. **Vehicle** — Grid selection with make, engine, body type, plate, series, chassis
3. **Rental** — Duration, type, period, fee
4. **Photo** — Camera capture or file upload
5. **Terms** — Liability acknowledgment checkbox

Submitted records are logged to the browser console.
